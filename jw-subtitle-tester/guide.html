📥 How to Install the Extension

Option 1: Firefox Add-on Store One-Click Install

  1. Visit the official khtranslator Firefox Add-on Page.
  2. Click the blue "+ Add to Firefox" button.
  3. Click "Add" in the browser prompt to confirm. You're ready to go!

Option 2: Google Chrome / Microsoft Edge / Brave From ZIP File

  1. Download the khtranslate-chrome.zip file.
  2. Extract (Unzip) the downloaded zip file into a folder on your computer (e.g. khtranslate-chrome).
  3. Open your browser and navigate to:
    • Chrome: chrome://extensions/
    • Edge: edge://extensions/
    • Brave: brave://extensions/
  4. Turn ON the "Developer mode" toggle (located in the top-right corner).
  5. Click the "Load unpacked" button (top-left) and select the extracted folder.
  6. The khtranslator extension icon will now appear in your browser extensions bar!

Option 3: Firefox Developer Mode From ZIP File

  1. Download the khtranslate-firefox.zip file and extract it.
  2. In Firefox, type about:debugging#/runtime/this-firefox in the address bar and press Enter.
  3. Click "Load Temporary Add-on...".
  4. Select the manifest.json file inside your extracted folder.

1. Translating Anime & Video Subtitles

Auto-Translate & Inject Recommended

When streaming anime or videos with foreign subtitles (English/Japanese), khtranslator extracts, translates, and displays them in Khmer:

  1. Open your streaming site (e.g. Anistream, Khanime, or KHFullHD) and play the video.
  2. Click the extension icon in your browser toolbar. When player subtitles are detected, you will see a green "English Subtitles Detected!" card.
  3. Click "Auto Translate & Inject". The AI will translate all lines and overlay them onto the video player in real time.

Manual Subtitle File Upload

You can also translate and inject offline subtitle files stored on your computer:

  1. Drag & drop your subtitle file (.srt, .vtt, .ass, or .lrc) into the upload box in the extension popup.
  2. Select your Source Language (e.g., English, Japanese, Chinese) and set the Target Language to Khmer.
  3. Click "Translate & Inject" to immediately translate and sync subtitles with the active video player.
  4. Click "Save / Download" once finished if you want to export the translated subtitle file.

2. Translating Manga & Comic Pages

Visual Dialogue Inpainting on Manga Sites

Read online manga chapters in Khmer directly on reading platforms without switching tabs:

  1. Navigate to any supported manga chapter (e.g. on MangaKatana).
  2. Open the extension popup. The extension will automatically detect the manga title, current chapter, and total pages.
  3. Click "Auto Translate Manga". The AI will read each page, clean out the speech bubbles, and render natural Khmer text.

Manga Translation Modes

  • Normal Mode (Clean Speech Bubble Inpainting): Erases the original foreign text and repaints high-resolution Khmer text inside the dialogue bubbles. (Requires the Manga Server URL to be set to https://khdownloader.xyz).
  • Fast Mode (Instant Text Overlay): Overlays translation cards directly on top of dialogue blocks without image inpainting for maximum reading speed.

📥 如何安装本扩展

选项 1: Firefox 附加组件商店 一键安装

  1. 访问官方 khtranslator Firefox 附加组件主页。
  2. 点击蓝色 "+ Add to Firefox"（添加到 Firefox） 按钮。

1. 如何翻译视频字幕 (动漫)

自动翻译与注入 推荐

在播放带有外语字幕的动漫视频时，扩展程序可自动提取、翻译并在播放器上叠加高棉语：

  1. 打开视频播放页面（例如 Anistream、Khanime 或 KHFullHD）并播放视频。
  2. 点击浏览器右上角的扩展图标。检测到字幕时将显示绿色的 "English Subtitles Detected!" 卡片。
  3. 点击 "Auto Translate & Inject"。AI 将自动完成翻译并在视频播放器中渲染高棉语字幕。

本地字幕文件手动上传

您也可以翻译并加载电脑中保存的本地字幕文件：

  1. 将字幕文件（.srt、.vtt、.ass 或 .lrc）拖入扩展弹窗中的上传区域。
  2. 选择源语言并设置目标语言为高棉语。
  3. 点击 "Translate & Inject" 立即翻译并与当前视频播放器同步加载。
  4. 完成后可点击 "Save / Download" 导出保存翻译好的字幕文件。

2. 如何翻译漫画图片

漫画网页对白即时擦除翻译

在漫画网站上直接阅读高棉语版本的漫画章节：
